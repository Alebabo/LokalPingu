# Training data

`synthetic/tourism-intents.jsonl` is generated by `scripts/train_tourism_intent_model.py`.
Every row is labelled `synthetic: true`. It contains English tourism enquiries for eleven
message-routing intents. No customer data or personal data is used.

`synthetic/tourism-intents-v2.jsonl` is the active second-round dataset generated by
`scripts/train_tourism_intent_model_v2.py`. It contains 19,800 records with broader free-text
phrasing, multiple simultaneous intents, light typing errors, and chat abbreviations. Every
record remains synthetic and English-only.

The hackathon brief in `file.pdf` recommends MASSIVE as an intent dataset, but the PDF
contains dataset references rather than training records. Synthetic data fills that gap for
the MVP. It must not be treated as evidence of field performance.
